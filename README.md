# my-portfolio

José R. Gutierrez's professional portfolio — a Nuxt 3 site, statically generated (SSG). See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for the spec-driven development workflow this project follows.

Available in Spanish (default, unprefixed routes) and English (`/en/*`), both pre-rendered at build time.

## Project setup

```
npm install
```

### Develop with hot-reload

```
npm run dev
```

### Run the test suite

```
npm run test
```

### Lint

```
npm run lint
```

### Type-check

```
npm run typecheck
```

### Build the static site

```
npm run generate
```

Output goes to `.output/public/` — servable by any static host (this project's own deployment: a bare nginx container, see `Dockerfile`). Includes `robots.txt` and a `sitemap_index.xml` (+ one XML sitemap per locale under `__sitemap__/`) generated by `@nuxtjs/sitemap` — `sitemap.xml` itself is a static redirect page to the index, not the crawlable file (see `.specs/007-seo-foundations/spec.md`'s Amendments for why).

### Preview a production build locally

```
npm run preview
```
